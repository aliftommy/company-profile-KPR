# Company Profile KPR

Website company profile untuk Kopi Padu Rasa (KPR), bisnis kopi to go dengan 28 toko di Sulawesi Selatan. Nama brand ditulis dua kata: "Kopi Padu Rasa", bukan "Padurasa". Di teks yang terlihat pengunjung pakai kata **"toko"** (EN **"store"**), bukan "outlet" (permintaan pengguna 18 Okt 2026; nama kode seperti `.outlet`, `OUTLET`, `OutletList`, `outlets.ts` sengaja tetap). Sebagian konten (alamat toko, cerita) masih placeholder `[...]`.

## Menjalankan

- Next.js 16 (App Router, TypeScript 5, React 19). Node.js ≥ 20.9.
- `npm run dev` (pengembangan, http://localhost:3000), `npm run dev:wifi` (bisa dibuka dari HP di WiFi yang sama), `npm run build` lalu `npm run start` / `npm run start:wifi` (versi produksi).
- Semua halaman dirender statis (○ Static) saat build.
- `allowedDevOrigins` di `next.config.ts` (rentang IP lokal 192.168/10/172.16–31) wajib ada: tanpanya Next.js 16 memblokir `/_next/hmr` untuk alamat selain localhost, React tidak aktif, dan di HP semua tombol mati (halaman tetap tampil). Uji tombol HP lewat CDP pakai `Input.dispatchTouchEvent` (touchStart/touchEnd); `Input.synthesizeTapGesture` di Edge headless tidak memicu `click`.
- `next dev` membuat/menulis ulang `AGENTS.md` sendiri (bisa dimatikan dengan `agentRules: false`).
- Aturan utama dari pengguna: **jangan ubah layout atau frame**. Saat migrasi ke Next.js, tampilan dibandingkan per piksel dengan versi HTML lama (selisih ≤0,02%, kecuali pita "Petunjuk arah" yang bergeser 2px karena panah "→" memakai font cadangan).

## Struktur

- `app/` halaman: `page.tsx` (beranda), `tentang/`, `menu/`, `lokasi/`, `kemitraan/`, `kontak/`; `layout.tsx` (header, footer, `<main id="konten">`, skrip awal bahasa); `globals.css` (CSS asli versi statis, nama kelas tidak diubah).
- `components/`: `SiteHeader` (client; header + laci menu `<dialog>`), `SiteFooter` (server), `LangMenu` (dropdown bahasa, 3 varian: header/drawer/footer), `LanguageProvider` (state bahasa + judul tab), `T` (teks dua bahasa), `HeroSlider` (client; hero beranda), `ProductCard`, `MenuTabs` (client; tidak dipakai sejak 21 Okt 2026, disimpan kalau tab dikembalikan), `OutletList` (client; pencarian), `Icons`.
- `data/`: `site.ts` (WhatsApp, sosmed, urutan NAV, judul tab per halaman), `products.ts` (produk, kategori tab, favorit, harga), `outlets.ts` (daftar toko; `WILAYAH` = { id: "Sulawesi Selatan", en: "South Sulawesi" } (dua bahasa seperti `JAM_BUKA`) dan `JAM_BUKA` = 24 jam berlaku untuk semua, bisa ditimpa per toko; `JUMLAH_TOKO` = jumlah baris, dipakai di semua teks "28 toko" & judul tab; `maps` kosong → `linkMaps()` membuka pencarian Google Maps "Kopi Padu Rasa <nama> Sulawesi Selatan"). Konten yang sering berubah diedit di sini.
- Toko (18 Okt 2026): 28 nama dari pengguna (Agus Salim … Parepare); angka di teks situs otomatis dari `JUMLAH_TOKO`. Ejaan yang dirapikan: Bougevnville → Bougenville, Barombomg → Barombong, Pajjajaiang → Pajjaiang. Alamat & link maps akan diisi pengguna sendiri.
- `public/assets/`: `img/icon-web.png` (logo/favicon), `img/produk/web/*.webp` (foto produk web), `fonts/warung-kopi*.otf`. URL tetap `/assets/...`.
- `foto-asli/produk/`: foto produk asli dari pengguna (PNG 2000×3000, 4–6 MB). `foto-asli/1L.jpeg`: poster Seliter (1280×1600). `foto-asli/produk/foto-toko.png`: foto depan toko (1122×1402). `foto-asli/produk/Fast order.png`: banner hero "Pesan Cepat?"
